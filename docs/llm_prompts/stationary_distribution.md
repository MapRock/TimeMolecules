* Prompt: How do I calculate the stationary distribution for a Markov model in TimeSolution?

* Abstract: The stationary distribution (also known as the steady-state or long-run probability distribution) of a Markov model gives the proportion of time the process will spend in each event as it runs indefinitely. In TimeSolution, this is computed by retrieving the transition matrix for a given ModelID via the ModelMatrix table-valued function, validating that it is square and stochastic, then applying power iteration (typically 15 iterations) until the probability vector converges. The resulting probabilities are persisted in the dbo.Model_Stationary_Distribution table, which stores one row per event containing ModelID, Event, and Probability. Users can run the calculation for a single ModelID by calling stationary_distribution(ModelID=123) from TimeSolution.py or for all models at once by executing the script without parameters. This enables analysis of the eventual equilibrium behavior of any business process captured as a Markov model.
