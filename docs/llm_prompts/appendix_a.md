Prompt: What is the Enterprise Intelligence framework and its Enterprise Knowledge Graph (EKG)?

Abstract: The Enterprise Intelligence framework builds an Enterprise Knowledge Graph (EKG) consisting of three core parts: a domain Knowledge Graph (KG) authored by subject matter experts using Semantic Web standards, a central Data Catalog (DC) that serves as the ontology for all data sources, tables, columns, and members, and two BI-derived structures — the Insight Space Graph (ISG) and Tuple Correlation Web (TCW) — that are passively constructed from actual BI analyst query activity. BI data is chosen as the foundation because it is already highly curated, cleansed, and trusted. The ISG captures salient insights from visualizations (trends, spikes, periodicity), while the TCW records tuples and their Pearson correlations and conditional probabilities across time series. Together they create a single integrated source of enterprise insights that links back to the original data catalog and knowledge graph.
