Prompt: How do I build a Time Molecules Markov model process from selected events, optional event transforms, and property filters?

Abstract: A Time Molecules Markov model process converts selected event histories into a reusable transition model by defining an event set, materializing the matching events, and generating probabilities for movement from one event to the next. The process supports both ordinary event rollups, where several detailed events are renamed to a common analytical event, and property-aware transforms, where an event can be split into more specific derived events based on its parsed properties. Property filters can further narrow the selected event population before the model is built, allowing the same process to be analyzed under different contextual conditions. The result is a repeatable workflow for turning raw event streams into Markov models that can be compared, filtered, transformed, and reused by SQL procedures, tutorials, and AI-agent workflows.
