Prompt: How can Time Molecules use OpenTelemetry-style event payloads, event properties, case properties, and Bayesian probabilities to infer hidden states in process data?

Abstract: Time Molecules treats events as timestamped observations with structured payloads, similar to OpenTelemetry events. Event payloads are stored in `dbo.EventProperties` through `ActualProperties`, `IntendedProperties`, `ExpectedProperties`, `AggregationProperties`, and `TriggerFunction`, while case-level context is stored in `dbo.CaseProperties` through `Properties` and `TargetProperties`. Parsed structures such as `dbo.EventPropertiesParsed`, `dbo.vwEventPropertiesParsed`, `dbo.CasePropertiesParsed`, and `dbo.vwCasePropertiesParsed` make these JSON-style attributes queryable and link them to `dbo.Sources` and `dbo.SourceColumns` for lineage. These properties provide the conditions used by `dbo.CreateUpdateBayesianProbabilities` to calculate probabilities such as `PB|A` and `PA|B` in `dbo.BayesianProbabilities`. Hidden states, such as machine wear, operator compensation, fatigue, or process drift, can be inferred from event sequences, properties, and related processes, then stored as properties or synthetic events. `dbo.HiddenMarkovModels()` combines Bayesian and Markov transition probabilities into a unified view for process-aware analysis, dimensional models, Data Vault, semantic layers, and knowledge graph linkage.
